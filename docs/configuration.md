# Configuration

BBE-Quest stores all configuration in `~/.bbe/`.

---

## `bbe.yaml`

The master configuration file. Created by [`bbe config`](commands/config.md) and updated by [`bbe setup`](commands/setup.md) and [`bbe install`](commands/install.md).

### Schema

```yaml
cluster:
  name: my-cluster          # Talos cluster name (set after bbe setup)
  context: admin@my-cluster # Kubernetes context name passed to helm --kube-context

storage:
  type: local               # "local" or "aws"
  aws:
    bucket_name: my-bucket  # S3 bucket name (only when type is "aws")

packages:
  - name: bbe-networking    # Installed package name
    version: 0.1.0          # Installed chart version
  - name: bbe-media
    version: 0.1.1
```

### Fields

| Field | Type | Description |
|---|---|---|
| `cluster.name` | string | The Talos cluster name, set during `bbe setup` |
| `cluster.context` | string | The `kubectl`/`helm` context (`admin@<cluster-name>`) |
| `storage.type` | `local` \| `aws` | Where to persist config files |
| `storage.aws.bucket_name` | string | S3 bucket name (required when `type: aws`) |
| `packages[]` | list | Packages installed via `bbe install` |
| `packages[].name` | string | Helm chart name (e.g. `bbe-media`) |
| `packages[].version` | string | Installed chart version |

---

## Cluster Config Files

Generated by `talosctl gen config` during `bbe setup` and stored alongside `bbe.yaml`:

| File | Description |
|---|---|
| `controlplane.yaml` | Talos machine config applied to the control plane node |
| `worker.yaml` | Talos machine config applied to worker nodes |
| `talosconfig` | `talosctl` client credentials and endpoint config |

---

## AWS S3 Storage

When `storage.type: aws` is configured, every write to `~/.bbe/` is mirrored to the configured S3 bucket. The bucket is created automatically with:

- **SSE-S3 encryption** enabled by default
- **Versioning** enabled — every config update creates a new version in S3

On a new machine, run `bbe config` to pull the existing config files down from S3.
